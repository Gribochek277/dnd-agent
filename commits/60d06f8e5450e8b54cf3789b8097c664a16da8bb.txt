feat(pdf): add spell data parser (PH0-T2)
Parse spell entries from PDF text extraction results into structured Spell objects.

Models:
- Spell record with all D&D 5e spell properties (name, level, school, components, etc.)
- SpellEffects discriminated union (8 types: damage, healing, condition, etc.)
- Supporting info records (SpellDamageInfo, SpellSaveInfo, SpellAreaInfo, etc.)

Parsing:
- SpellParser orchestrator (consumes PdfTextExtractionResult from PH0-T1)
- SpellHeaderDetector: regex-based detection of 3 header formats (full, compact, single-line)
- SpellFieldExtractor: extracts Casting Time, Range, Components, Duration, Classes
- SpellEffectParser: parses description text into structured effects (damage, healing, conditions, movement, objects)
- SpellAggregator: multi-source aggregation with class/subclass union

IO:
- SpellJsonWriter for JSON serialization with polymorphic effects

Tests:
- 86 tests covering all parser components (header detection, field extraction, effect parsing, full integration)
- Build: 0 warnings, 0 errors
