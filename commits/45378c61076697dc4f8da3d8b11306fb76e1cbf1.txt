Add `parse spells` subcommand for pre-processing D&D 5e spell PDFs into structured JSON.

- Parse PDF using PdfPig with layout-aware text extraction
- Extract and parse spells via existing SpellParser
- Write structured SpellCollection to JSON output
- Configurable default PDF path and output directory
- Page range selection (--page-range option)
- Dry-run mode for validation (--dry-run option)
- Progress indicators via Spectre.Console Status spinner
- Summary table showing parse results and spell level distribution
