causing repeated prompts during internal agent tool-call loops. When the
LLM called a tool without required params, got an error, and looped, each
iteration printed another "assistant: " making it look like the assistant
was repeating the same question.

Fix: Add assistantPrinted flag — print label only on first TextDeltaEvent
of each turn, skip in ToolCallEndEvent handler, reset on DoneEvent/ErrorEvent.
